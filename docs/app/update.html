Update the board's firmware

Firmware

Steps

  1. If the Mic array app is connected to the board, tap ✕ there first: only one page can use the USB port.
  2. Plug the board into this device's USB port.
  3. Tap Flash and pick the board (it shows as USB JTAG/serial debug unit or ESP32-S3).
  4. Wait for “Done” (about half a minute), then go back to the app and tap Connect USB.

If it can't connect

Hold the board's BOOT button, press and let go of RESET (or unplug and replug it while holding BOOT), let go of BOOT, and tap Flash again. After flashing that way, press RESET once so the new firmware starts. If the other USB method is offered, try it too.
